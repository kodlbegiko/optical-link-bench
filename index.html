不是取代 QR，而是把 QR 變成整條光學鏈路的一部分。

短資料仍用標準 QR；大資料才切入高速 optical payload。使用者看到的是同一個「Show → Scan → Receive」流程。

真正要贏的不是 Peak，
而是 Useful Goodput。

如果 300 KB/s 的 raw channel 最後因為掉 frame、FEC、重試只剩 120 KB/s，它就沒有贏。Optical Link 將「完整檔案 / wall-clock / hash pass」作為產品級 KPI。

Roadmap 由「研究問題」驅動。

先修量測，再找 QR ceiling，再建立 Binary Optical Grid。每一階段只在上一個 evidence gate 通過後前進。

  1. NOW
    Measurement Integrity

    CV zero-window、phase accounting、TX/camera timestamps、JSON telemetry、metric tests。

  2. 0.21
    Decoder Sampling Causality

    12 / 18 / 24 Hz / camera-driven，以 counterbalanced order 排除 drift。

  3. 0.22
    Display Timing

    rAF、integer refresh holds、transition tearing 與實際 presentation jitter。

  4. 0.23+
    Browser QR Ceiling

    建立未來 Optical HS 必須公平擊敗的 matched baseline。

  5. GRID
    Optical Grid V0

    QR bootstrap + persistent locators + binary data field + temporal pilot + FEC + hash。

  6. HS
    Adaptive High-Speed Mode

    自動調整 grid、presentation rate、FEC；之後再測 multilevel / color / OFDM。

性能目標是 Gate，不是宣稱。

每個數字都必須由真實檔案、完整 hash 與重複測試支撐。

高速 optical link 的難點不是「畫更多格子」，而是把 display timing、camera exposure、rolling shutter、decoder compute 與 FEC 分開量測。

Timing

Timer jitter、refresh alignment、transition tearing。

Camera

Rolling shutter、auto exposure/focus、browser frame delivery。

Geometry

Perspective、ROI drift、handheld motion。

Compute

Full-frame fallback、main-thread blocking、FEC cost。

Methodology

Time drift、zero-window bias、unfair codec comparison。

Product

Cross-device variability、security assumptions、large-log handling。

先把量測做對，再開始追速度。

目前可直接進入 V0.20.8 TX / RX benchmark。新的 Optical HS codec 仍是設計與 roadmap，不會把未完成的東西包裝成成果。
